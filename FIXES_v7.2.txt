VZHDO dashboard v7.2 — исправления

1. Универсальный поиск
- нормализация регистра и повторных пробелов;
- Протоколы: номер, поручение, содержание, исходное/разрешённое СП, ход исполнения и структура (куратор, руководители СП/НОР, руководитель подразделения, совместное исполнение);
- e-Өтініш: номер, автор, вид, содержание, СП и организационные руководители; Ф.И.О. обычного ответственного исполнителя намеренно НЕ является поисковой размерностью;
- Входящие: рег. номер/дата, содержание, СП, структура и должность;
- поиск внутри multi-select также нормализован;
- глобальный поиск отображается среди активных фильтров и учитывается в их счётчике.

2. Страница «Загрузка»
Для 1.xlsx / 2.xlsx / 3.xlsx показываются: файл, лист, строка заголовков, валидные записи, пропущенные строки, диапазон дат, дата/время загрузки, ERROR/WARNING/INFO.
При неудачной замене предыдущий корректный набор данных сохраняется, а ошибка показывается в карточке.
Для structure.xlsx показываются статус, записи, руководители СП, директора НОР, дата загрузки и фактический статус логотипа.

3. Data Quality
Добавлены уровни ERROR / WARNING / INFO и сводный блок на странице «Загрузка».
Проверяются: структура, неизвестный/пустой статус, некорректные даты, отсутствующий срок, неизвестное СП протокола, Ф.И.О. не найдено/неоднозначно, расхождение исходного СП со structure.xlsx, конфликт статуса и срока протокола, возможные дубликаты идентификаторов.
Предупреждения отображаются также в карточке записи.

Архитектура GitHub Pages сохранена:
- structure.xlsx находится в корне репозитория;
- 1.xlsx / 2.xlsx / 3.xlsx загружаются пользователем через интерфейс и в GitHub не требуются;
- assets/xlsx.full.min.js и assets/vzhdo-logo.png находятся в assets/.
